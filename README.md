# Readme Widya Trijuli

## Tugas 1

### Step Clone
Clone repository menggunakan command di bawah
```
git clone https://github.com/afteroffice466/bootcamp-batch3.git
```

### Install Depedencies
Maven Repository
Rest Assured
Copas latest version ke pom.xml dari repo yang baru saja di clone

```
<dependency>
    <groupId>io.rest-assured</groupId>
    <artifactId>rest-assured</artifactId>
    <version>5.5.1</version>
    <scope>test</scope>
</dependency>
```

### Run Test
Klik Running
